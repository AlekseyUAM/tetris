# Тетрис-словарь — дизайн

**Дата:** 2026-09-26
**Статус:** утверждён к реализации

## Цель

Веб-игра (PWA) для Android-смартфона: классический тетрис, совмещённый с
тренажёром английских слов. Когда игрок собирает заполненную линию, появляется
вопрос на перевод; линия сгорает только при правильном ответе.

## Обзор механики

- Классический тетрис (поле 10×20, 7 тетромино, вращение, soft/hard drop).
- При заполнении линии игра встаёт на **паузу** и показывает вопрос.
- Вопрос: слово на английском + 4 варианта перевода на русский, **или наоборот**
  (направление выбирается случайно для каждого вопроса).
- **Правильный ответ** → линия сгорает (с анимацией), начисляются очки.
- **Неправильный ответ или истечение времени** → кратко показывается правильный
  ответ (~1.5 с), начисляется штраф, линия **остаётся** на поле.
- Если одной фигурой закрыто несколько линий — задаётся **отдельный вопрос на
  каждую линию** по очереди; каждая линия сгорает независимо по своему ответу.
- На ответ даётся **таймер 10 секунд**; не успел — считается неверным ответом.

## Технический стек

- **Vanilla TypeScript + HTML5 Canvas** — без UI-фреймворков.
- **Vite** — dev-сервер и сборка (тестирование в браузере телефона по локальной сети).
- **Vitest** — юнит-тесты чистой логики (TDD).
- **PWA** — `manifest.json` + service worker: установка на домашний экран, офлайн-режим.
- Ориентация: **portrait**.

Отклонённые альтернативы: React/Svelte (оверкилл для Canvas-игры), Phaser/игровой
движок (лишний вес), Flutter/нативный Kotlin (выше порог входа, не нужно для v1).

## Архитектура (модули)

Чистая логика отделена от отрисовки и ввода — ядро полностью тестируемо.

### `engine/` — чистая игровая логика (без DOM)
- `Board` — сетка 10×20, фиксация фигур, поиск заполненных линий, удаление линий и
  падение блоков сверху.
- `Piece` — 7 тетромино, состояния вращения, генерация (bag-рандомайзер).
- `collision` — проверка столкновений и границ.
- Гравитация, подсчёт очков и уровня.

### `vocab/` — словарь и вопросы
- Встроенный словарь в JSON: массив `{ en: string, ru: string }` (порядка 200–500 слов).
- Выбор случайного слова для вопроса.
- Генерация вопроса: правильный ответ + **3 дистрактора**, выбранных случайно из
  других слов словаря (не совпадающих с правильным переводом).
- Случайный выбор направления вопроса: EN→RU или RU→EN.

### `game/` — конечный автомат состояний
- Состояния: `Playing → LineCleared(Question) → Playing → … → GameOver`.
- Оркестрирует, что показывать и когда ставить паузу.
- Обрабатывает очередь из нескольких линий (по вопросу на линию).

### `ui/` — отрисовка и ввод (Canvas + DOM)
- Отрисовка поля, фигур и HUD (счёт, уровень, следующая фигура) на Canvas.
- **Разноцветные фигуры** — классические цвета тетромино:
  I — голубой, O — жёлтый, T — фиолетовый, S — зелёный, Z — красный, J — синий, L — оранжевый.
- **Анимация сгорания линии** — при правильном ответе линия вспыхивает и затухает
  (~250 мс) перед удалением, затем блоки сверху падают.
- Экран вопроса — оверлей: слово, 4 крупные кнопки-варианта, полоса таймера.
- Сенсорное управление.

### `storage/` — сохранение
- Рекорд и настройки в `localStorage`.

## Управление (сенсорное, portrait)

- Свайп влево/вправо — двигать фигуру.
- Свайп вниз — soft drop.
- Тап — поворот.
- Свайп вверх — hard drop.
- На экране вопроса — 4 крупные кнопки-варианта (удобны для пальца).

## Правила и очки

- Уровень растёт каждые **10** сгоревших линий; скорость падения увеличивается с уровнем.
- Очки за сгоревшую линию — базовые очки × уровень.
- Штраф за неверный ответ / таймаут — фиксированный вычет (напр. −50 очков).
- Game over — стакан переполнен (новая фигура не помещается).

## Поток игры вокруг вопроса

1. Фигура фиксируется; движок находит заполненные линии.
2. Игра встаёт на паузу, заполненные линии подсвечиваются (пока не сгорают).
3. Для каждой заполненной линии по очереди показывается вопрос-оверлей
   (слово + 4 варианта + таймер 10 с).
4. Правильно → анимация сгорания, линия удаляется, блоки падают, начисляются очки.
5. Неправильно / таймаут → ~1.5 с показывается правильный ответ, начисляется штраф,
   линия остаётся на поле.
6. Когда все заполненные линии обработаны — игра продолжается.

## Тестирование

- **TDD** для `engine/` и `vocab/` — чистые функции: коллизии, вращение,
  детект и удаление линий, генерация вопроса и дистракторов, выбор направления.
- UI, анимация и сенсорный ввод проверяются вручную в браузере телефона.

## Вне области v1 (YAGNI)

- Темы/уровни сложности словаря, пользовательское редактирование словаря.
- Статистика изученных слов, аккаунты, синхронизация.
- Звук/музыка (можно добавить позже).
- Публикация в Google Play (сначала работающая PWA).
