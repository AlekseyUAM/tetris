# Тетрис-словарь

Веб-игра (PWA) для Android: классический тетрис, совмещённый с тренажёром
английских слов. Когда собираешь заполненную линию, появляется вопрос на перевод —
линия сгорает только при правильном ответе.

## Как играть

- Классический тетрис: поле 10×20, 7 разноцветных тетромино, вращение, soft/hard drop.
- Заполнил линию → игра встаёт на паузу и показывает вопрос:
  английское слово + 4 варианта перевода на русский (или наоборот).
- На ответ даётся 10 секунд.
- **Правильно** → линия сгорает (с анимацией), начисляются очки.
- **Неправильно или время вышло** → показывается правильный ответ, штраф к очкам,
  линия остаётся на поле.
- Несколько линий сразу → по вопросу на каждую линию.

## Управление (сенсорное)

| Действие      | Жест                  |
|---------------|-----------------------|
| Двигать влево/вправо | свайп влево/вправо |
| Soft drop     | свайп вниз            |
| Hard drop     | свайп вверх           |
| Поворот       | тап                   |

## Технологии

- Vanilla **TypeScript** + HTML5 **Canvas**
- **Vite** — dev-сервер и сборка
- **Vitest** — юнит-тесты (TDD)
- **PWA** — установка на домашний экран, офлайн-режим

## Структура проекта

```
src/
  engine/    чистая игровая логика (доска, фигуры, коллизии, линии) — без DOM
  vocab/     встроенный словарь и генерация вопросов
  game/      конечный автомат состояний игры
  ui/        отрисовка на Canvas, экран вопроса, сенсорный ввод
  storage/   рекорд и настройки (localStorage)
public/      PWA-ассеты (манифест, иконки, service worker)
docs/        спецификации дизайна
```

## Разработка

> Проект на этапе настройки; команды появятся вместе с `package.json`.

```sh
npm install     # установка зависимостей
npm run dev     # dev-сервер Vite (тестирование в браузере телефона по локальной сети)
npm test        # юнит-тесты Vitest
npm run build   # production-сборка в dist/
```
