# Тетрис-словарь

Веб-игра (PWA) для Android: классический тетрис, совмещённый с тренажёром
английских слов. Когда собираешь заполненную линию, появляется вопрос на перевод —
линия сгорает только при правильном ответе.

## Как играть

- Классический тетрис: поле 10×20, 7 разноцветных тетромино, вращение, soft/hard drop.
- Заполнил линию → игра встаёт на паузу и показывает вопрос:
  английское слово + 4 варианта перевода на русский (или наоборот).
- На ответ даётся 10 секунд.
- **Правильно** → линия сгорает (с анимацией), начисляются очки.
- **Неправильно или время вышло** → показывается правильный ответ, штраф к очкам,
  линия остаётся на поле.
- Несколько линий сразу → по вопросу на каждую линию.

## Управление

Сенсорное (телефон):

| Действие             | Жест              |
|----------------------|-------------------|
| Двигать влево/вправо | свайп влево/вправо |
| Soft drop            | свайп вниз         |
| Hard drop            | свайп вверх        |
| Поворот              | тап                |

С клавиатуры (на компьютере, для отладки):

| Действие             | Клавиша       |
|----------------------|---------------|
| Двигать влево/вправо | ← / →         |
| Поворот              | ↑             |
| Soft drop            | ↓             |
| Hard drop            | Пробел        |

## Технологии

- Vanilla **TypeScript** + HTML5 **Canvas**
- **Vite** — dev-сервер и сборка
- **Vitest** — юнит-тесты (TDD)
- **PWA** — установка на домашний экран, офлайн-режим

## Структура проекта

```
src/
  engine/    чистая игровая логика (доска, фигуры, коллизии, линии) — без DOM
  vocab/     встроенный словарь и генерация вопросов
  game/      конечный автомат состояний игры
  ui/        отрисовка на Canvas, экран вопроса, сенсорный ввод
  storage/   рекорд и настройки (localStorage)
public/      PWA-ассеты (манифест, иконки, service worker)
docs/        спецификации дизайна
```

## Запуск в браузере

1. Установить зависимости (один раз):

   ```sh
   npm install
   ```

2. Запустить dev-сервер:

   ```sh
   npm run dev
   ```

3. Открыть в браузере адрес, который выведет Vite:

   - **на компьютере:** `http://localhost:5173/`
   - **на телефоне** (в той же Wi-Fi-сети, что и компьютер): адрес из строки
     `Network`, например `http://192.168.1.119:5173/`

Правки кода подхватываются автоматически (hot reload). Управление — см. раздел
[«Управление»](#управление): на компьютере с клавиатуры, на телефоне жестами.

### Проверка PWA (офлайн, установка)

Собрать и запустить production-версию (service worker работает только в ней):

```sh
npm run build && npm run preview
```

Открыть адрес превью, затем в Chrome DevTools (F12) → вкладка **Application**:
Manifest покажет иконку и portrait-режим, Service Workers — активный воркер.
Офлайн-режим: поставить галочку **Offline** и обновить страницу — игра загрузится
из кэша (после первого онлайн-визита). На телефоне: меню браузера →
«Установить приложение» / «Добавить на главный экран».

## Прочие команды

```sh
npm test        # юнит-тесты Vitest
npm run build   # production-сборка в dist/
npm run preview # локальный просмотр собранной версии
```
